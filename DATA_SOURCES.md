# Data Sources and Verification

SOLARIS uses representative, educational values and calls them out as approximate and game-calibrated wherever they are displayed in the UI.

## Launch vehicles
- Rocket Lab Electron payload guides
- ISRO SSLV / PSLV payload user guides
- SpaceX Falcon 9 user guide and public launch docs
- ULA Atlas V payload manuals

## Orbits and mission geometry
- NASA orbital mechanics references and public mission design documentation
- GMAT (General Mission Analysis Tool) examples and canonical orbit definitions
- NASA Mission Design Lab and JPL concept maturity references

## Instruments and spacecraft bus components
- NASA Small Spacecraft Technology State-of-the-Art report
- CubeSat 101 and related NASA/industry mission architecture guides
- Public instrument specifications from NASA and ESA missions

## Ground segment and operations
- NASA Near Space Network and Deep Space Network documentation
- ISRO ISTRAC and commercial ground station references
- CSA and public small-satellite operations guidance

## Real mission library
- NASA mission pages and public mission architecture documents
- ISRO mission publications and launch overview pages
- ESA / NASA Earth observation mission documentation

## Methodology note
This project is intended for educational use as a mission-design training tool. It is not a flight-certified engineering product and should not be used for real mission approval or operational planning.
