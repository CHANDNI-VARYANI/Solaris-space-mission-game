# Demo Script

## 3-minute walkthrough
1. Open the landing page and choose the Student CubeSat scenario.
2. Review the objective, constraints, and budget.
3. Select a launch vehicle and orbit with the compatibility check.
4. Add a small multispectral camera and confirm the power and data implications.
5. Run the simulation and show the mission fails because of a design margin issue.
6. Explain the root-cause chain in the report.
7. Adjust the design, add safer margins, and rerun.
8. Show the mission succeeding and compare against a reference mission.

This demonstrates the key learning loop: design, simulate, diagnose, and redesign.
